# FIELDWAVE SF Policy Radar Case Study Package

FIELDWAVE SF Policy Radar is a lightweight legislative intelligence prototype: it turns public meeting agendas into a focused review queue for cultural policy decision-making and teamwork, while preserving human judgment for high-context policy interpretation. This repository is a public-facing, portfolio-safe case study package for demonstrating the FIELDWAVE SF Policy Radar project in job applications, interviews, and stakeholder conversations without exposing private operating details, credentials, live Notion data, or the full product roadmap. 

## Package Contents

- [`case-study.md`](case-study.md) — narrative case study suitable for a portfolio page, application attachment, or interview prep.
- [`demo-guide.md`](demo-guide.md) — a short credential-free demo script using dry-run mode.
- [`ip-protection-notes.md`](ip-protection-notes.md) — guidance on what is safe to share publicly and what should remain private.
